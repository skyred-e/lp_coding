# LPコーディングサンプル
公開されている無料のデザインカンプを元に、仕様を確認しながらコーディングを行いました。
カンプ提供元：<https://code-jump.com/lp-menu/>

公開ページ：<https://skyred-e.github.io/lp_coding/>
ソースコード：<https://github.com/skyred-e/lp_coding>

## ■使用技術
 - HTML/CSS/JavaScript
 - レスポンシブ対応
 - JavaScriptによるハンバーガーメニュー
 - CSSアニメーションによるメインビジュアルの切り替え
 - JavaScriptによるスクロール連動アニメーション

## ■実装上の工夫
ハンバーガーメニューやスクロール連動アニメーションは実務でも使用している自作のJavaScriptスクリプトを使用しています。
いずれも繰り返し使用する処理を共通化し、案件ごとの実装コストを抑えられるよう設計しました。

スクロール連動アニメーションでは、対象要素への発火処理とアニメーションの表現を分離しています。
アニメーションの内容はCSS側で自由に定義できるため、同じスクリプトをさまざまな演出に利用できます。

ハンバーガーメニューでは、操作ボタンとメニュー本体をそれぞれ個別に指定できるため、HTMLの構造に応じて柔軟に配置できます。

メインビジュアルには@keyframesを使用し、JavaScriptに依存せず、時間経過に応じて画像が切り替わるアニメーションを実装しました。

## ■動作確認
PC版はChrome、Firefox、Edgeで動作を確認、またモバイル版はAndroid端末で動作を確認しています。

Lighthouseを使用し、PC・モバイルそれぞれの表示について、パフォーマンス・アクセシビリティ・おすすめの方法・SEOの各項目を計測しました。
パフォーマンスを改善するため、メインビジュアルをWebP形式に変換してファイルサイズを削減しました。
変換後は画質も確認し、表示品質を保ちながら最適化を行っています。
結果、パフォーマンススコアはモバイル版Lighthouseで80点未満から95点前後に改善しました。
